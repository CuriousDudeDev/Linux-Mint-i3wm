Setup instructions:-

1.Always maintain a backup before, incase, anythign goes wrong.

2.First ensure the walpaper and the i3 config are in your respective folders

3.Copy the config files of i3 and put the wallpaper in the location specified in the config file (Pictures/wallpaper.png)

4.Log out of the session and choose the i3 wm session

5.If anything looks broken, you might need to search for it manually os use an ai chatbot, this repo does not provide a solution for every problem

6.If everything looks good. 

7.Star installing essential tools like polybar, rofi, lxappearance(linuxmint)....

8.Then use the dot files to copy and fine tune the, as per your wish
